# AI Plagiarism Checker (Module 1, Task 2)

Програма для перевірки текстової подібності (оновлена після тестування).

## Функціонал:
- Підтримка форматів **.txt** та **.docx**
- Алгоритм **TF-IDF + cosine similarity**
- Графічний інтерфейс (**Tkinter**)
- Логування у файл `app.log`
- Конфігурація через `config.json`
