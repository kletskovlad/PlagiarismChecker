AI Plagiarism Сhecker (v1.1.0)

Простий інструмент для перевірки схожості документів на основі алгоритмів машинного навчання.


 - Ключові можливості:
   
Smart Analysis: Використання TF-IDF для аналізу контексту, а не просто слів.

Формати: Працює з .txt та .docx.

Privacy: Повна обробка локально (ніяких хмарних сервісів).

Logging: Детальний журнал подій у app.log.


 - Що нового у гілці task1 (+fix):

Стабільність: Додано валідацію порожніх файлів (захист від крашу).

Надійність: Впроваджено try-except для безпечного читання дисків.

Чистий код: Код приведено до стандарту PEP 8.


 - Швидкий запуск
   
Встанови бібліотеки: pip install scikit-learn python-docx

Запусти: python main.py

Протестуй: python test_logic.py


 - Структура
   
main.py — Інтерфейс (GUI).

test_logic.py — Логіка та Unit-тести.

config.json — Налаштування версії.
