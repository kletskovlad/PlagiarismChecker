# AI Plagiarism Checker (Module 1, Task 1)
Програма для автоматизованої перевірки текстової подібності.

## Функціонал:
- Підтримка форматів **.txt** та **.docx**.
- Використання алгоритму **TF-IDF** та косинусної міри.
- Графічний інтерфейс на базі **Tkinter**.
- Система логування подій у файл `app.log`.
- Зовнішня конфігурація через `config.json`.
