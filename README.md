# AI Plagiarism Checker (v1.2.0)

Простий інструмент для перевірки схожості документів на основі алгоритмів машинного навчання (TF-IDF та косинусна міра).

## Ключові можливості:
  **Smart Analysis**: Використання TF-IDF для аналізу контексту та лексичного складу документів.
  
  **Формати**: Підтримка файлів .txt та .docx.
  
  **Privacy**: Повна локальна обробка даних без використання хмарних сервісів.
  
  **Logging**: Детальний журнал подій та помилок у файлі `app.log` з підтримкою UTF-8.
